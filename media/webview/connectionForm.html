Server

Fills host, port, user, password, database and options below; nothing is saved until you click Save.
Host may also be a full connection string (mongodb:// or mongodb+srv:// for Atlas); username / password below are added to it.
When set, the port is resolved by SQL Server Browser (UDP 1434) and the port above is ignored.

Timeouts

seconds
How long to wait while connecting. Running queries have no timeout: stop them with Cancel.

Permissions

Only statements that do not change data can run (SELECT, WITH, DECLARE, SET @var, SHOW); UPDATE / INSERT / DELETE / DDL / EXEC are blocked before they reach the server.
